TRANSFORMER GUIDE

Before Transformers, sequence models used Recurrent Neural Networks. Each step $t$ computes a hidden state from the previous one:

$$h_t = f\!\left(W \cdot h_{t-1} + U \cdot x_t + b\right)$$

This creates two hard problems.

RNN / LSTM — sequential

Vanishing gradients (BPTT):

$$\frac{\partial \mathcal{L}}{\partial h_0} = \prod_{t=1}^{T} \frac{\partial h_t}{\partial h_{t-1}}$$

Each Jacobian has spectral radius <1 → gradient shrinks exponentially → early tokens contribute nothing.

No parallelism: $h_{t+1}$ depends on $h_t$ → GPU cores sit idle.

Transformer — parallel

All $n$ tokens processed simultaneously via self-attention. $\mathcal{O}(n^2 d)$ but fully GPU-parallelizable. Every token attends to every other token in one forward pass — no recurrence, no vanishing gradient through time.

Vaswani et al. (2017) — "Attention Is All You Need." Eliminated recurrence entirely. English→German translation at the same BLEU as the best RNN ensembles, trained in 3.5 days on 8 GPUs instead of weeks.

A neural network operates on real-valued vectors — raw text must be converted to integers first. The tokenization strategy directly affects model capacity, multilingual coverage, and inference cost.

Byte Pair Encoding (BPE):

Initialize vocab = all characters. Greedily merge the most frequent adjacent pair. Repeat ~50k times. "unhappiness" → ["un", "happiness"] or ["un","happy","ness"] depending on corpus. Handles any unseen word by decomposing into known sub-units.

The embedding matrix has size:

$$E \in \mathbb{R}^{V \times d_{\text{model}}}$$
Vocab size trade-off: larger $V$ → fewer tokens per sequence (faster) but larger $E$. GPT-2 = 50,257 · GPT-4 ≈ 100,256 · Llama 3 = 128,256. Bigger vocabs improve multilingual coverage.

Token IDs are arbitrary labels. An embedding maps each ID to a dense vector in $\mathbb{R}^{d_{\text{model}}}$ where geometric proximity encodes semantic similarity. These are learned parameters.

$$E \in \mathbb{R}^{V \times d_{\text{model}}}, \qquad \text{embed}(\text{id}) = E[\text{id}]$$ $$\cos(\mathbf{a},\, \mathbf{b}) = \frac{\mathbf{a} \cdot \mathbf{b}}{\|\mathbf{a}\| \cdot \|\mathbf{b}\|} \;\in\; [-1,\, 1]$$

Linear structure in embedding space — emerges from training corpus statistics:
King − Man + Woman ≈ Queen

$\cos\!\left(E[\text{King}]-E[\text{Man}]+E[\text{Woman}],\; E[\text{Queen}]\right) \approx 0.89$. Not programmed — the model discovers this linear structure from co-occurrence statistics. Mikolov et al. (word2vec, 2013).

$d_{\text{model}}$ is a core hyperparameter: GPT-2 small = 768 · GPT-3 = 12,288 · Llama 3 70B = 8,192 · PaLM = 18,432. Larger $d$ → more expressive but attention memory scales $\mathcal{O}(n^2 d)$.

Self-attention is permutation-equivariant — shuffle the input tokens and you get the same output values, just shuffled. Without position info, "Dog bites man" and "Man bites dog" are identical to the model.

Same tokens, different order → entirely different meaning:
Sinusoidal positional encoding — Vaswani et al. (2017):
$$\text{PE}(\text{pos},\; 2i) = \sin\!\left(\frac{\text{pos}}{10000^{2i/d_{\text{model}}}}\right)$$ $$\text{PE}(\text{pos},\; 2i+1) = \cos\!\left(\frac{\text{pos}}{10000^{2i/d_{\text{model}}}}\right)$$
pos = token index · i = dimension index (0 to dmodel/2)
Each dimension oscillates at a different frequency → unique fingerprint per position.

Key property: $\text{PE}(\text{pos}+k)$ can be written as a linear function of $\text{PE}(\text{pos})$ → dot products between PE vectors encode relative distance. Modern models often use RoPE (Llama) or ALiBi instead.

What gets added per token:
embed("cat") → [0.2, −0.5, 0.8, ...] semantic meaning
PE(pos=2) → [sin(2/1), cos(2/1), sin(2/100), ...] position signal
$\mathbf{x}_2$ = element-wise sum fed into layer 1 attention
The sinusoidal basis ensures $\text{PE}(\text{pos}+k) = T \cdot \text{PE}(\text{pos})$ for some linear transform $T$ that depends only on $k$, not $\text{pos}$ — so relative distances are learnable from attention dot products.

Scaled Dot-Product Attention is the core operation. Each token projects to three vectors Q, K, V via learned weight matrices. $Q \cdot K^\top$ scores how much each token attends to each other; softmax normalizes; the result weights V.

$$\text{Attention}(Q,\, K,\, V) = \text{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$
Q, K ∈ ℝn×d_k   V ∈ ℝn×d_v   output ∈ ℝn×d_v
√d_k scaling: without it, dot products grow large → softmax saturates → gradients ≈ 0

Projections — each token $\mathbf{x}_i \in \mathbb{R}^{d_{\text{model}}}$ → Q, K, V:
Q $\mathbf{x} W_Q$,  $W_Q \in \mathbb{R}^{d_{\text{model}} \times d_k}$   "what am I searching for?"
K $\mathbf{x} W_K$,  $W_K \in \mathbb{R}^{d_{\text{model}} \times d_k}$   "what do I advertise?"
V $\mathbf{x} W_V$,  $W_V \in \mathbb{R}^{d_{\text{model}} \times d_v}$   "what do I contribute?"
Multi-Head Attention:
$\text{MultiHead}(Q,K,V) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\, W_O$
$W_O \in \mathbb{R}^{hd_v \times d_{\text{model}}}$. Each head learns different relationship types.
GPT-3: $d_{\text{model}}=12{,}288$, $h=96$ heads, $d_k=d_v=128$. Attention matrix is $n \times n$ — quadratic in context length. 100k tokens → 10B values per layer. FlashAttention (Dao et al., 2022) avoids materializing the full matrix, reducing memory from $\mathcal{O}(n^2)$ to $\mathcal{O}(n)$.

After attention aggregates information across tokens, each position is processed independently by a two-layer FFN. Geva et al. (2021) showed FFN layers function as key-value memories — the model's factual knowledge is largely stored here.

$$\text{FFN}(\mathbf{x}) = \text{GELU}(\mathbf{x} W_1 + b_1)\, W_2 + b_2$$
W₁ ∈ ℝd_model × d_ff   W₂ ∈ ℝd_ff × d_model   d_ff = 4 × d_model (standard ratio)
GPT-2: 768→3072 · GPT-3: 12288→49152
GELU(x) = x · Φ(x)   smoother than ReLU, better empirically for LLMs
💡
Why expand then compress?

Attention handled cross-token communication. The FFN refines each token individually — expanding to $d_{\text{ff}}$ (4× wider) to apply nonlinearity, then compressing back. $W_1$ rows act as "keys" that activate on patterns, $W_2$ rows as "values" that output the corresponding information.

GPT-3's 175B params split roughly 2/3 FFN, 1/3 attention. Mixture of Experts (MoE): activate only $k$ of $n$ expert FFNs per token (Mixtral: 2 of 8). Same quality as a dense model at $1/k$ the compute — GPT-4 reportedly uses MoE.

One Transformer block = Attention + FFN. Two more operations are essential: residual connections and Layer Normalization. Without them, training 96-layer networks is numerically unstable.

$$\mathbf{x} \leftarrow \mathbf{x} + \text{Attention}\!\left(\text{LayerNorm}(\mathbf{x})\right)$$ $$\mathbf{x} \leftarrow \mathbf{x} + \text{FFN}\!\left(\text{LayerNorm}(\mathbf{x})\right)$$ $$\text{LayerNorm}(\mathbf{x}) = \boldsymbol{\gamma} \odot \frac{\mathbf{x} - \mu}{\sigma + \varepsilon} + \boldsymbol{\beta}$$
μ, σ = mean and std across dmodel dimension (per token)
γ, β = learned scale and shift parameters
💡
Why residuals prevent vanishing gradients: $$\frac{\partial \mathcal{L}}{\partial \mathbf{x}} = \frac{\partial \mathcal{L}}{\partial \text{out}} \cdot \left(1 + \frac{\partial F}{\partial \mathbf{x}}\right)$$

The $+1$ ensures gradient magnitude $\geq 1$ even when the sublayer contributes nothing ($\partial F/\partial \mathbf{x} \approx 0$). This is what makes 96-layer training stable.

Pre-LN vs Post-LN: Post-LN (original paper) applies LayerNorm after the residual add — slightly better when perfectly tuned but brittle. Pre-LN (GPT-2+) applies LN before the sublayer — more stable. Both add a final LayerNorm before the output head.

The final layer's hidden state is projected to a logit vector of size $V$ via a linear layer — weight-tied with the embedding matrix $E$. Softmax converts logits to a probability distribution over the next token.

$$\text{logits} = \mathbf{x}_{\text{final}} \cdot E^\top \;\in\; \mathbb{R}^V$$ $$P(t_i) = \frac{\exp(\ell_i / \tau)}{\displaystyle\sum_j \exp(\ell_j / \tau)}, \qquad \tau > 0 \text{ (temperature)}$$ $$\mathcal{L} = -\frac{1}{n}\sum_{t=1}^{n} \log P\!\left(t_t \;\middle|\; t_1, \ldots, t_{t-1}\right)$$

Decoding strategies — argmax is rarely used in practice:
Temperature $\tau$: $\tau \to 0$ = greedy argmax · $\tau = 1$ = raw softmax · $\tau > 1$ = uniform. Chat: $\tau \approx 0.7$. Code: $\tau \approx 0.1$.
Top-$k$: zero out all but the $k$ highest logits before softmax. Simple; requires tuning $k$.
Top-$p$ (nucleus): keep smallest set of tokens with cumulative $P \geq p$. Width adapts — narrow when confident, wide when uncertain. $p = 0.9$ is typical.
Beam search: maintain $b$ candidate sequences. Better for translation; produces generic text for open-ended generation.

KV-cache: cached $K$ and $V$ tensors from previous tokens avoid recomputing them each step. Reduces per-token cost from $\mathcal{O}(n \cdot L)$ to $\mathcal{O}(L)$. Without it, generation over 4096 tokens would be ~4096× slower.
